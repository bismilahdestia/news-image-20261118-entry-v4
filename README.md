A newspaper front page summing up Wednesday 18 November 2026: Trump lands in Manila for the ASEAN summit, the Crimean Bridge is hit again, drones fly over Bahrain, and Nvidia doubles its revenue — plus the day's other news in a bottom ticker. The program draws the whole page itself in Node with only the standard library: it decodes four fresh news photographs, lays them out in a 2×2 front-page grid under a masthead, and sets every headline, region kicker and caption with a small bitmap face drawn in the code.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
